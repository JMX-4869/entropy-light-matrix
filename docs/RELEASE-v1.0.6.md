## v1.0.6 · 补上「扫描全部模组」开关

> 有人反馈**检测不到模组**，而正确答案其实是"开关一下就好"—— 但这个开关
> 在界面上根本不存在。

### 问题

v1.0.2 起，扫描**默认只覆盖当前播放集里启用的模组**（起因是那条
「我只想排序，怎么把我订阅的 mod 全部一起弄了」）。

同时埋了一个配置字段 `scan_all_mods`，`app.py` 也读了它。但是：

```
$ grep -c scan_all_mods smd/web/index.html
0
```

**界面上一个入口都没有。** 设置页里翻遍了也找不到 —— 所以遇到
"检测不到模组"的人，只能卡在那儿。

### 修

三层都补上了：

| 层 | 加了什么 |
| --- | --- |
| `config.py` | 字段本来就有 |
| `app.py` | `set_scan_all_mods()`，存盘并记日志 |
| `webui.py` | `setScanAllMods` 桥接 |
| `index.html` | 设置页的开关卡片 + 启动时回填状态 |
| `i18n.js` | 中英词条 |

开关在**设置页**，紧挨着「在模组列表显示已退订的空条目」。文案里写清了
"改完要重新扫描才生效"。

### 检测不到模组时按这个顺序查

1. **看顶部的播放集下拉框** —— 括号里是 `(启用数/总数)`。如果启用数是 0，
   就是选了空播放集，或者这个播放集里全停用了
2. **打开设置页的「扫描全部模组」** —— 连未启用的也一起检测
3. **看「游戏目录」** —— 应该指向 `文档\Paradox Interactive\Stellaris`
4. **看那个目录下的 `mod\`** —— 里面是 `.mod` 文件，还是一堆文件夹？
   程序只认 `.mod` 文件，手动解压出来的文件夹扫不到
