安装

普通使用（推荐）

  1. 到 Releases 下载 StellarisModDoctor-Setup.exe
  2. 双击安装。不需要管理员权限，不弹 UAC
  3. 桌面会出现「熵光矩阵」，双击运行

安装位置：%LOCALAPPDATA%\Programs\StellarisModDoctor， 控制面板里可正常卸载。需要 Edge WebView2（Win10 1803+ 与 Win11 自带）。

从源码运行

运行时只依赖 pywebview 一个第三方库。

git clone https://github.com/JMX-4869/entropy-light-matrix.git
cd entropy-light-matrix
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py

两条不会让步的原则

这类工具最让人不放心的两件事，这里都做成了硬约束。

1 · 模组开关永远由你决定

  • 求解器只负责说清「为什么建议关」， 关不关由你逐项拍板
  • 代码里 approved_disable() 是唯一的真相来源 —— 没经你确认的模组，一个都不会被关
  • 即便开了「允许关闭模组」，也需要 本地求解器与 AI 同时判定该关才会列进方案
  • 「关闭」只改启用状态，不删除你的模组文件

2 · AI 内容必须你显式授权

  • 隐私闸门集中在 smd/ai/analyze.py 的 ensure_ready()，不是散在各个调用点 —— 漏一处就意味着模组内容会在你不知情时发出去
  • 默认关闭。不开这个开关，AI 相关功能一律拒绝执行
  • API Key 只存在本机 %LOCALAPPDATA%， 不会进安装包、不会进仓库 （仓库里有 tools/audit_secrets.py 专门核查这件事）
