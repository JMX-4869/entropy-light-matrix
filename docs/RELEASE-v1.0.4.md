## v1.0.4 · 新增轻量版

> 同一个程序，两套界面。**默认还是网页版**，加 `--light` 启动轻量版。

### 为什么要有两套

实测内存占用（打包后，递归整棵进程树）：

| 界面 | 工作集 | 私有内存 | 进程数 |
| --- | --- | --- | --- |
| **轻量版** | **43 MB** | 20 MB | 2 |
| 网页版 | 616 MB | 391 MB | 8 |

网页版的 616 MB 里，主进程只占 10 MB，**剩下 600 MB 全在 Edge WebView2**。
那是 Chromium 的架构成本 —— 我这几天试过让它降下来，全部无效：

```
--js-flags=--max-old-space-size=128    ±0.0%
--renderer-process-limit=1             −1.1%
--disable-gpu                          −0.2%
三者合用                                +1.0%
```

而且查 WebView2 的命令行发现：**这些参数根本没传进去** ——
被 pywebview 硬编码的 `AdditionalBrowserArguments` 覆盖了。
要真让它生效得改 pywebview 的内部实现，版本一升级就会失效。

所以不跟 Chromium 较劲，另做了一套原生界面。

### 功能一样全

轻量版不是阉割版。8 个页签覆盖原版的全部核心链路：

| 页签 | 内容 |
| --- | --- |
| **模组** | 列表、逐项启停、详情、打开工作坊 |
| **冲突** | 检测结果、双击看成因与建议 |
| **排序** | 最优顺序、手动上下移动 |
| **诊断** | 崩溃报告 / 日志分析 / 成就影响 / 联机校验 |
| **补丁** | 候选、自动生成、已安装管理 |
| **知识库** | 时之虫档案搜索 + 提问 |
| **AI** | 接管排查 / 分析排序 / 测试连接 |
| **设置** | 路径、API Key、模型、语言 |

还带：播放集切换与重命名、备份与回滚。

**没做的只有**：主题系统（那是 CSS 的事）、星图背景、动效。

### 怎么用

```bash
StellarisModDoctor.exe --light     # 轻量版
StellarisModDoctor.exe             # 网页版（默认）
```

命令行也认得到：`--light` 是独立开关，不影响其它参数。

### 视觉

配色**直接取自网页版「群星（默认）」主题的色值**，不是另抄一份：

```
深空蓝底 #05080f   面板 #0b1220   星蓝 #4a9eda   金 #c9a961   淡蓝白字 #d8e6f5
```

`smd/ui_light.py` 里是 `from .theme import BUILTIN` 然后读同一份 tokens，
所以以后换主题，两套界面不会有一边掉队。

极简不等于难看。Tkinter 没有圆角、阴影、渐变，能用来自造质感的只有三样，
全部用上了：

* **留白** —— 页内 padding 14×12，行高 27px，控件之间不贴着
* **层级** —— 顶栏 / 内容区 / 状态栏三段不同深浅，眼睛一进来就知道哪块干什么
* **克制** —— 只有「应用」一个按钮染强调色。到处高亮等于没有高亮

金色只用在两处：品牌名和表头。群星那种高级感，八成来自金色出现得少。

### 底线没变

* **绝不自动关闭模组** —— 轻量版同样只关 `approved_disable()` 里的
* 轻量版不提供「批量批准」入口；有未决定的冲突时会提示你去网页版
* 开关模组必须逐个点，且写回前弹确认

### 顺带修的

* 安装器：窗口内容 406px 塞进 400px 高的窗口 → 改 `side="bottom"` 让按钮恒定在底部（v1.0.3 已修，这里记一笔）
* 轻量版启动时会把所有表格刷一遍 —— 没数据的表各自落一句占位提示，
  切过去不会看到一片纯黑以为界面坏了

## 功能一览

| 功能 | 一句话 |
| --- | --- |
| 冲突检测 | 找出模组间重定义同一脚本对象的冲突，给严重度与影响条数 |
| 最优排序 | 分层 + 拓扑排序，翻译模组自动置顶 |
| 兼容补丁 | 生成覆盖补丁模组，可回滚 |
| 崩溃报告 | 翻译 `exception.txt` / `error.log`，配成因注释 |
| 日志分析 | 高频报错归类，AI 可解读 |
| 影响成就的模组 | 按游戏自带 `checksum_manifest.txt` 查，可一键或自选关闭 |
| 联机校验排查 | 找会导致校验码不一致的模组 |
| AI 接管 | 汇总 12 类数据源做全面排查 |
| 时之虫档案 | 8689 条游戏知识库，可检索/发命令 |
| 播放集管理 | 自动发现官方 + Irony，准确对应，可切换/重命名 |
| **轻量版** | Tkinter 界面，43 MB，同一套功能 |

## 说明

* 求解器**不会自动关闭你的任何模组** —— 关不关由你逐项决定
* AI 功能默认关闭，需要你显式打开隐私开关
* API Key 只存在本机 `%LOCALAPPDATA%`，不会上传、不进安装包
* 两个版本共用同一份配置（`%LOCALAPPDATA%\StellarisModDoctor\config.json`）
