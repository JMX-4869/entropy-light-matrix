## v1.0.2 · 更新内容

> 从 v1.0.1 升上来的看这一节就够。**首次使用**可以往下翻功能一览。

### ⚠️ 如果你下过 v1.0.1，请务必换这一版

v1.0.1 的安装包在那几天被**就地替换过 3 次**（修安装器、加 GPT-6、加播放集），
但版本号一直没动 —— 也就是说同样叫 1.0.1 的两个文件，内容可能完全不同。
现在正式发 1.0.2，把那段修复期收进一个明确的版本号。

### 1. 安装包装不上（最严重）

**症状**：只下载了 `StellarisModDoctor-Setup.exe` 一个文件，
选完安装位置后提示「安装失败：找不到 StellarisModDoctor.exe」。

**原因**：打包时只把图标塞进了安装包，没塞程序本体；查找逻辑又只认
"安装包旁边那个文件"。所以从构建目录里双击没事，单独拿出来就装不了。

**已修**：安装包现在**自包含**。体积 10.3 → 22.5 MB，就是程序本体被打进去了。

### 2. 安装位置选 `D:/` 会把文件倒进盘根

**症状**：安装位置填 `D:/`，程序文件散落在 D 盘根目录。

**原因**：把"用户选的位置"直接当成落地目录了。

**已修**：自动在选定位置下创建 `StellarisModDoctor` 文件夹。
界面上也加了一行「实际安装到：…」，填完就能看到落点。

### 3. 扫描范围忽略播放集

**症状**：「我只想排序，怎么把我订阅的 mod 全部一起弄了」。

**原因**：扫描抓的是"有文件的都扫"，不看启用状态、不看属于哪个播放集。

**已修**：默认只扫**当前播放集里启用的**模组。想扫全部可在设置里打开开关。

### 4. 播放集：多来源自动发现 + 准确对应

**症状**：同一套配置，在官方启动器和 Irony Mod Manager 里名字和数量都不一样，
工具只认一个。

**实测**：

```
官方库：「IronyModManager」 74 条
Irony ：名字就叫「1」       76 条
```

**已修**：

* 两处都自动读取，界面上标出 `[官方启动器]` / `[Irony Mod Manager]`
* 用**工坊 id 集合的重合度**（≥80%）判断哪些是同一套 —— 不用名字，
  因为名字会变（你能改名、不同工具起不同名），id 不会
* 同一套会互相标注：「↔ Irony Mod Manager「1」是同一套」
* 选中哪个来源，就按那个来源的数据解析启用状态与加载顺序
* 模组页顶部的下拉可以直接切换，旁边还有「重命名」

> Irony 的播放集不支持在本工具里改名（那要写它自己的数据库，有损坏风险）。
> 官方库的可以改，只改名字不动 id，先备份、事务写入、失败回滚。

### 5. 支持 GPT-6 Sol / Luna 等推理模型

新增 `gpt-6-sol` / `gpt-6.1-sol` / `gpt-6-luna`。

**顺带修掉一个一直存在的哑弹**：模型列表里原有 `o4-mini`，
但请求无条件带 `temperature` —— 而推理模型**拒绝采样参数**，
选了必然 400，错误信息看起来还像网络问题。

现在自动识别推理模型（`o` + 数字开头、`gpt-6` 开头），
改发 `reasoning_effort`。设置页多了「思考深度」下拉。

> 说句实话：`gpt-6-sol` 的 1.05M 上下文对本工具是**过剩的**。
> 当前发给 AI 的排查材料约 25K token，200K 上下文的中端模型足够用。

### 6. AI 生成的界面主题会校验对比度

以前只检查"是不是合法 `#rrggbb`"。所以模型给出
`文字 #333` / `背景 #111`（几乎同色）也照收，用户拿到一套**字都看不见**的界面。

现在按 WCAG 检查 12 组关键配对（正文 4.5、次要文字 3.0、按钮文字 4.5、状态色 3.0）。
不达标**自动修正**：把前景往背景的反方向推（浅底压暗、深底提亮），背景一律不动。

实测：故意造的全暗主题 8 项不达标 → 0 项。

### 7. 一些静默 bug

这几个一直存在、但不报错，所以特别难发现：

* **崩溃页整张表空白** —— `data-i18n` 标在含子元素的标签上时，
  翻译机制会清空子节点，`#crashSub` 消失后渲染函数抛异常
* **崩溃诊断的「异常类型/信息」永远是空的** —— 取值键名与解析结果对不上
* **调用栈丢失帧号** —— 同一个函数名重复十几遍，看不出崩溃点
* **语言有两个来源** —— localStorage 与配置文件互相打架
* **扫描结果一离开页面就消失** —— `load_mods()` 会清空扫描报告
* **任务栏提示不更新** —— 局部变量遮蔽了翻译函数

## 功能一览

| 功能 | 一句话 |
| --- | --- |
| 冲突检测 | 找出模组间重定义同一脚本对象的冲突，给严重度与影响条数 |
| 最优排序 | 分层 + 拓扑排序，翻译模组自动置顶 |
| 兼容补丁 | 生成覆盖补丁模组，可回滚 |
| 崩溃报告 | 翻译 `exception.txt` / `error.log`，配成因注释 |
| 日志分析 | 高频报错归类，AI 可解读 |
| **影响成就的模组** | 按游戏自带 `checksum_manifest.txt` 查，可一键或自选关闭 |
| **联机校验排查** | 找会导致校验码不一致的模组 |
| AI 接管 | 汇总 12 类数据源做全面排查 |
| 时之虫档案 | 8689 条游戏知识库，可检索/发命令 |
| 播放集管理 | 自动发现官方 + Irony，准确对应，可切换/重命名 |
| 界面英文化 | 1173 个 i18n 键，中英完全对齐 |
| 主题 | 5 套内置 + AI 生成（带对比度校验） |

## 说明

* 求解器**不会自动关闭你的任何模组** —— 关不关由你逐项决定
* AI 功能默认关闭，需要你显式打开隐私开关；不开的话模组内容一个字都不会发出去
* API Key 只存在本机 `%LOCALAPPDATA%`，不会上传、不进安装包
* 两个版本共用同一份配置（`%LOCALAPPDATA%\StellarisModDoctor\config.json`）
