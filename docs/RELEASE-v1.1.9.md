## 熵光矩阵 1.1.9

### 奇点协议扩展（随安装包分发）

安装包自带「奇点协议」扩展。装完到「扩展」页点「启动」起 OGAS 控制台，
再点「打开控制台」—— 在**软件自己的窗口**里打开，不是浏览器标签页。

**OGAS 本体要单独下载**（GPL-3.0 独立项目，不随本软件分发）：
https://github.com/V2t-Nostalgia/OGAS

下载后把目录路径写进
`%LOCALAPPDATA%\StellarisModDoctor\dlc\singularity-protocol\runtime\ogas_home.txt`
（一行，只有路径），或者设环境变量 `SMD_OGAS_HOME`。

### 全面扫盘

设置 → 路径 → 「全面扫盘」。逐盘找游戏目录、用户数据和工坊目录，
找到的列出来，每条带「用这个」，点了直接写进配置。

盘符可以自己选（Ctrl 多选），不选就全扫。三块盘实测 5 秒。

### 学习版路径覆盖（5 项）

设置 → 路径 → 学习版专用，五项都能单独指定：

| 项 | 留空时 |
| --- | --- |
| 存档目录 | 用户数据目录/save games |
| 启动器数据库 | 用户数据目录/launcher-v2.sqlite |
| 日志目录 | 用户数据目录/logs |
| 崩溃转储目录 | 用户数据目录/crashes |
| 额外模组目录（可多个） | 不扫 |

自动识别也加强了：游戏目录及上一级会递归三层找特征目录
（含 `save games` + `mod` + `logs` 三样才算）。

### AI 消耗预估

所有要花 token 的地方都先给预估：批量生成补丁、单条补丁、一键翻译。

**并且会自校准**：跑完一批后用「实际 ÷ 原始估算」修正系数（指数平滑），
存到 `%LOCALAPPDATA%\StellarisModDoctor\ai_token_ratio.json`。
跑得越多，预估越贴实际。

批量跑完显示真实用量（服务商返回的 `usage`，不是估算）。

### 修掉的

· **安装程序装不上**：`NameError: _install_bundled_extensions is not defined`
  —— 函数定义写在了 `if __name__ == "__main__"` 之后，`main()` 执行时名字还不存在
· **设置页路径全是空白**：`get_settings` 用 `json.dumps(default=str)`，
  把 `Paths` dataclass 序列化成了 `"Paths(user_dir='...')"` 一整个字符串
· **改了路径一会儿自己变回去**：`render()` 定期回填输入框，加了脏标记
· **路径卡片没有保存按钮**（唯一那个在页面顶部，改路径的人看不到）
· **路径为空时点「打开」没有任何反馈**
· **批量 token 预估不显示**：失败分支被静默清空，看起来像没这个功能
· **「工坊目录」改名「模组路径」**，说明本地 mod 在用户数据目录下的 `mod\`
· **八个模组定位判错**（界面类被判成大型重做、小调整被判成大型重做、
  中文大型内容被体量规则误判、补丁类没归位）
· **设置页三条路径加「浏览」按钮**，选完直接保存
· **21 处模板字符串漏 `$`**（界面上直接显示 `${t('原因：$')}`）
· **全面排查被渲染进了加载顺序页**
