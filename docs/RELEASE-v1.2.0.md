## 修复

### 冲突检测跑完，列表一片空白

统计卡片、类型分布都对，下面就是不出条目。三个错叠在一起：

1. 筛选条的几个 chip 渲染函数写的是旧 id（那个容器被 `innerHTML` 整个替换之后就没了），`null.innerHTML` 抛异常，把后面的列表渲染整条中断
2. 状态刷新时误用了一个不存在的变量，`undefined.length` 抛异常，整个刷新流程从中间断掉
3. WebView2 用了持久缓存，**改了代码但界面还渲染旧 HTML** —— 前几版你看的其实是缓存

### 切换播放集 / 勾「扫描全部模组」报 is not a function

后端一直有这两个方法，桥接也写好了，唯独前端那个手写对象漏了两行。

### 使用指南点开后右侧整片空白

入口用了导航项的 class，导航初始化会覆盖它的点击事件，然后拿一个不存在的页面名去切换 —— 所有页面被隐藏。

### 最大化按钮报 querySelector 不是合法选择器

把 `t(...)` 的源码字面量拼进了 CSS 选择器，而且属性值里含中文和括号。

### 其他

- 安装器里有个函数定义写在 `if __name__ == "__main__"` 后面，导致 1.1.9 的安装包直接 NameError（这个必须有）
- 设置页路径全是空白、改了路径一段时间不保存会还原
- 全面扫盘扫不到游戏和工坊目录

## 开发者向

仓库里加了 `tools/web_lint.py`，跑一次能查出这几类问题：

1. 前端调的方法，后端没有
2. 前端引用的对象方法，那个手写对象里没有定义
3. 引用的元素 id 不存在
4. CSS 选择器里拼了源码
5. 重复 id
6. 静态 HTML 里写了模板串

这次靠第 2 条和第 3 条直接抓到两个真 bug。

## 升级提醒

如果你之前用过 1.1.9，**装完这个版本之后请完全退出再重新打开**。

原因：界面用了 WebView2 的持久缓存，旧版进程还在跑的时候，新界面不会被加载 —— 你看到的可能还是旧版的样子。如果装完发现界面没变化，删掉这个目录再启动：

```
%LOCALAPPDATA%\StellarisModDoctor\webview\EBWebView
```

（1.2.0 之后的版本我已经在构建流程里自动清这个目录，但升级这一刻需要你手动来一次。）
