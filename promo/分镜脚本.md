# 熵光矩阵 · 宣传片分镜脚本

**规格**：1920×1080 · 30fps · 约 60 秒 · 无配音（纯画面 + 文字）
**成品**：`promo/熵光矩阵-宣传片-1080p.mp4`
**素材**：全部为软件**真实界面截图**，AI 只参与配色与排版

---

## 为什么不用 AI 生成画面

AI 视频模型画的"软件界面"是乱码假字，懂行的人一眼看穿。
这软件最大的卖点恰恰是**界面本身够漂亮**（5 套可切换主题），
所以画面全部用真实截图，只在片头/片尾用生成的星空氛围。

## 叙事主线：从崩溃到能玩

**不是功能罗列** —— 功能罗列的宣传片没人看完。这条线讲一件事：
> 你装了 94 个模组，游戏老崩，你不知道为什么，也不知道该关谁。
> 这个软件把它变成一次点击。

## 视觉规范

| 元素 | 取值 | 来源 |
| --- | --- | --- |
| 背景 | `#05080f` + 星空纹理 | 软件内置 stellaris 主题 |
| 主强调色 | `#38bdf8`（青） | 同上 |
| 次强调色 | `#a78bfa`（紫） | 同上 |
| 正文 | `#e6edf7` 微软雅黑 | Windows 自带 |
| 警示 / 成功 | `#f87171` / `#34d399` | 同上 |

**沿用软件自身的主题色**，片子看起来才像同一个产品，而不是随便配的。

## 运动设计

静态截图拼视频最容易做成"PPT 轮播"，所以：

1. **每张截图带缓慢推拉**（Ken Burns，最多放大 7%，焦点从左上漂到右下）
2. **文字逐条浮现**，不是整屏一次出现
3. **数字滚动**，开场与数据屏都有
4. **开场有呼吸光晕**（6Hz 正弦）
5. **截图带外发光 + 圆角描边**，像"贴在深空里的一块屏幕"

## 排版要点（试出来的）

- **文字放截图旁边，不压上去**：压上去必然挡住界面细节，而界面正是要展示的东西
- **截图按 16:10 裁一刀再放大**：原始截图 1384×911 直接铺会缩得很小、看不清界面；裁掉暗色留白后主体几乎大一倍
- **右上信息栏留白**：右侧不放满，视觉上有呼吸

## 怎么改

```powershell
# 1. 改分镜（场景函数 + SCENES 列表）
#    tools/make_promo.py

# 2. 只看排版，不渲全片（约 4 秒）
python tools/_promo_check.py
#   → promo/check_sheet.png 是各场景联络表

# 3. 渲染全部帧（1800 帧约 5 分钟）
python tools/make_promo.py

# 4. 编码成 MP4
python tools/make_video.py
python tools/make_video.py --crf 16     # 更高质量、文件更大
```

**为什么拆成"渲帧"和"编码"两步**：帧可以单独检查（某帧排版崩了能
立刻看出来），改码率时也不用重渲。合在一起的话每次都要等全流程。

## 中文竖排 / 字体注意

`font()` 会依次找 `msyh.ttc`（微软雅黑）→ `msyhl.ttc` → `Deng.ttf`
→ `simhei.ttf`。**Pillow 自带的默认位图字体不含汉字**，
找不到中文字体时中文会显示成方块 —— 换电脑跑这个脚本时留意一下。
