# 熵光矩阵 · 宣传片分镜脚本

**规格**：1920×1080 · 30fps · 约 78.5 秒 · **含背景音乐（无配音）**
**成品**：`promo/熵光矩阵-宣传片-1080p.mp4`（h264 + aac，12.7 MB）
**素材**：全部为软件**真实界面截图**，AI 只参与配色与排版
**音乐**：程序合成（`tools/make_music.py`），版权归项目所有

## 背景音乐

### 为什么不用免版权素材

素材库的许可条款参差不齐（有的要署名、有的禁止商用、有的禁止再分发），
而这段音乐要跟着仓库一起开源。**自己合成则版权完全归项目所有**，
也不会有"这段曲子被谁用过"的隐患。

而且程序生成能**精确对齐 78.5 秒**：素材库的曲子长度固定，
硬剪会在乐句中间断掉，一听就廉价。

### 音乐设计

| 项 | 取值 | 理由 |
| --- | --- | --- |
| 调性 | A 小调 | 太空/科技片标配。小调自带辽阔与克制，不像大调那样"喜庆"，不抢画面 |
| 和声 | Am → F → C → G | 每和弦 5.6 秒，循环铺满全片 |
| 层次 | 持续低音 + 铺底垫音 + 高频微光 + 脉冲 | 脉冲**35 秒后才进**，前半段保持"漂浮"；一上来就打拍子会像广告 |
| 混响 | 5 段延迟叠加 | 没有 scipy 做不了卷积混响，多次延迟叠加已经够糊出空间感 |
| 立体声 | 右声道延迟 12ms | 制造宽度 |

### 一个被客观指标抓出来的问题

第一版合成完，我用**频段能量占比**检查（音乐没法靠读代码判断对错）：

```
低频 <200Hz    35.4%      ← 太肥
中低 200-800   64.5%
中频 800-3k     0.0%      ← 完全没有
高频 >3k        0.0%      ← 完全没有
```

原因是**纯正弦波没有泛音**，能量全堆在基频，听起来发闷发糊。
过零率也印证了：只有 400~600 Hz。

修了三处：

1. 给垫音加奇次泛音层（3/5/7/11 次谐波）
2. 高频微光从基频 ×2 抬到 ×4~×6，真正进入 2~5kHz
3. 补一层**带通噪声**当"空气感"——真实弦乐的高频来自噪声成分，
   光靠正弦泛音还是太"合成器"

同时把低音从 0.30 压到 0.17：低频在能量上极占便宜（能量 ∝ 幅值²），
一开始就给太多。

最终：

```
低频 <200Hz    19.2%
中低 200-800   52.1%      ← 主体
中频 800-3k    22.7%
高频 >3k        5.9%      ← 从 0% 到有
```

0 削波（峰值 0.639）、分段 RMS 起伏 1.60x（缓，符合"铺底不抢戏"）。

### 音量

成品里音乐压到 **0.55**。这是**背景**音乐，盖过画面文字就本末倒置了。
解出来实测整体 RMS 0.043 —— 远低于画面直方图的量级，确实在"背景"位置。

## 为什么不用 AI 生成画面

AI 视频模型画的"软件界面"是乱码假字，懂行的人一眼看穿。
这软件最大的卖点恰恰是**界面本身够漂亮**（5 套可切换主题），
所以画面全部用真实截图，只在片头/片尾用生成的星空氛围。

## 叙事主线：从崩溃到能玩

**不是功能罗列** —— 功能罗列的宣传片没人看完。这条线讲一件事：
> 你装了 94 个模组，游戏老崩，你不知道为什么，也不知道该关谁。
> 这个软件把它变成一次点击。

## 运动设计

静态截图拼视频最容易做成"PPT 轮播"，所以：

1. **每张截图带缓慢推拉**（Ken Burns，最多放大 7%，焦点从左上漂到右下）
2. **文字逐条浮现**，不是整屏一次出现
3. **数字滚动**，开场与数据屏都有
4. **开场有呼吸光晕**（6Hz 正弦）
5. **截图带外发光 + 圆角描边**，像"贴在深空里的一块屏幕"

## 排版要点（试出来的）

- **文字放截图旁边，不压上去**：压上去必然挡住界面细节，而界面正是要展示的东西
- **截图按 16:10 裁一刀再放大**：原始截图 1384×911 直接铺会缩得很小、看不清界面；裁掉暗色留白后主体几乎大一倍
- **右上信息栏留白**：右侧不放满，视觉上有呼吸

## 怎么改

```powershell
# 1. 改分镜（场景函数 + SCENES 列表）
#    tools/make_promo.py

# 2. 只看排版，不渲全片（约 4 秒）
#    tools/_promo_check.py 会生成 promo/check_sheet.png 联络表
#    （临时脚本，需要时重建）

# 3. 渲染全部帧（2355 帧约 5 分钟）
python tools/make_promo.py

# 4. 编码成无声 MP4
python tools/make_video.py
python tools/make_video.py --crf 16     # 更高质量、文件更大

# 5. 合成音乐
python tools/make_music.py              # 生成 promo/music.wav

# 6. 混音（只重编音频，画面直接 copy，几秒出片）
python tools/mux_music.py
python tools/mux_music.py --music-vol 0.4   # 音乐更小声
python tools/mux_music.py --no-music        # 还原纯画面版
```

**为什么拆成这么多步**：帧、画面编码、音乐、混音各自独立。
换音乐时不该重编画面（`mux_music.py` 用 `-c:v copy`，几秒完成），
改码率时不该重渲帧，调排版时不该等编码。合在一起每改一样都要等全流程。

## 中文竖排 / 字体注意

`font()` 会依次找 `msyh.ttc`（微软雅黑）→ `msyhl.ttc` → `Deng.ttf`
→ `simhei.ttf`。**Pillow 自带的默认位图字体不含汉字**，
找不到中文字体时中文会显示成方块 —— 换电脑跑这个脚本时留意一下。
